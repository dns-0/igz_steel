# igz_steel Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `igz_steel`, an IngeTrazo extension that places AISC v16.0 steel shapes as parametric members, stretches them along any axis by drag or typed length, edits them in place, tags them for BIM, assigns layers, and produces a Bill of Materials.

**Architecture:** Pure-Python modules (`_db`, `_profiles`, `_geometry`, `_bom`) do all data and maths on tuples and dicts and are unit tested with pytest. Thin Qt/host modules (`_host`, `_tools`, `_dialog`, `_core`) convert to `QVector3D`/`Mesh`/`Group`, drive the IngeTrazo tool protocol, and wire menus, toolbar and dialogs. Host modules are stubbed under `tests/stubs/` so the Qt layer is also testable offscreen.

**Tech Stack:** Python 3.12-compatible code (the frozen app ships python312.dll), PySide6 (ships with IngeTrazo), IngeTrazo 0.5.8 Extension API 2, pytest, openpyxl (developer-only converter).

**Spec:** `docs/superpowers/specs/2026-10-13-igz-steel-design.md`

**Project root:** `C:\INGETRAZO EXTENSIONS\STEEL SHAPES EXTENSION` (all paths below are relative to it). Run commands from this folder in Git Bash.

## Global Constraints

- Every `.py` file starts with `# SPDX-License-Identifier: GPL-3.0-or-later`.
- No syntax newer than Python 3.12 (no PEP 695 generics, no `type` statements).
- Runtime imports limited to stdlib, PySide6 and IngeTrazo's own modules (`core.*`, `tools.base`, `views.*`). openpyxl only in `devtools/build_db.py`.
- All geometry in metres internally; `IN_M = 0.0254`.
- Package key is `KEY = "igz_steel"`; parameter block version `EXT_VERSION = 1`.
- `igz_steel/__init__.py` defines no `Tool` subclass (the loader instantiates every `Tool` subclass defined there with no arguments).
- Minimum member length 0.001 m, maximum 1000 m.
- IFC tolerance 5°: column when within 5° of vertical, beam when within 5° of horizontal, else member.
- Fillet arcs are 4 segments; round sections 8–96 segments, default 24.
- The AISC workbook is never copied into `igz_steel/`; only `data/aisc_v16.json` ships.
- Tests run with `.venv/Scripts/python -m pytest -q` and must pass before each commit.

## Review Focus

1. A typed length of `0`, a negative number, or a 2-tuple while placing must commit nothing and not raise. Test added in Task 10.
2. Any shape whose `kdes` is missing or whose fillet would not fit (tiny sections) must still build a closed outline with fillets on. Whole-database sweep test added in Task 6.
3. A selected group that is not a steel member, or a member the user exploded (`xform` is `None`), must be refused by Stretch/Edit with a message, never a traceback. Test added in Task 9.
4. A document without a `units` attribute (older file) must format in metres and kilograms rather than fail. Test added in Task 8.
5. A filter with no matches must leave the shape list empty and the Place button disabled, with no exception when Place is clicked anyway. Test added in Task 12.

```python
# SPDX-License-Identifier: GPL-3.0-or-later
"""Minimal stand-in for core.mesh: welded vertices, radial edges, faces."""
from PySide6.QtGui import QVector3D


def _key(p):
    return (round(p.x(), 6), round(p.y(), 6), round(p.z(), 6))


class Vertex:
    def __init__(self, position):
        self.position = position
        self.edges = set()


class Edge:
    def __init__(self, v0, v1):
        self.v0, self.v1 = v0, v1
        self.faces = []
        self.soft = False

    @property
    def a(self):
        return self.v0.position

    @property
    def b(self):
        return self.v1.position


class Face:
    def __init__(self, loop, holes):
        self.loop = loop
        self.hole_loops = holes
        self.attrs = {}

    def vertices(self):
        return [v.position for v in self.loop]

    def holes(self):
        return [[v.position for v in h] for h in self.hole_loops]


class Mesh:
    def __init__(self):
        self.faces = []
        self.edges = []
        self._verts = {}
        self._edge_map = {}

    def vertex(self, position):
        k = _key(position)
        v = self._verts.get(k)
        if v is None:
            v = Vertex(QVector3D(position))
            self._verts[k] = v
        return v

    def _link_edge(self, v0, v1):
        k = frozenset((id(v0), id(v1)))
        e = self._edge_map.get(k)
        if e is None:
            e = Edge(v0, v1)
            self._edge_map[k] = e
            self.edges.append(e)
            v0.edges.add(e)
            v1.edges.add(e)
        return e

    def add_face(self, loop_positions, hole_loops=None):
        loop = [self.vertex(p) for p in loop_positions]
        holes = [[self.vertex(p) for p in h] for h in (hole_loops or [])]
        face = Face(loop, holes)
        for lp in (loop, *holes):
            n = len(lp)
            for i in range(n):
                self._link_edge(lp[i], lp[(i + 1) % n]).faces.append(face)
        self.faces.append(face)
        return face
```

```python
DEFAULT_LAYER = "Layer 0"


class Layer:
    def __init__(self, name, visible=True, locked=False):
        self.name, self.visible, self.locked = name, visible, locked


def layer_of(entity):
    attrs = getattr(entity, "attrs", None)
    if attrs is not None:
        return attrs.get("layer") or DEFAULT_LAYER
    return getattr(entity, "layer", None) or DEFAULT_LAYER


def assign_layer(entity, name):
    value = None if name == DEFAULT_LAYER else name
    attrs = getattr(entity, "attrs", None)
    if attrs is not None:
        if value is None:
            attrs.pop("layer", None)
        else:
            attrs["layer"] = value
    elif hasattr(entity, "layer"):
        entity.layer = value
```

```python
# SPDX-License-Identifier: GPL-3.0-or-later
from abc import ABC, abstractmethod


class CommandRejected(Exception):
    pass


class Command(ABC):
    @abstractmethod
    def do(self, scene): ...

    @abstractmethod
    def undo(self, scene): ...


class History:
    def __init__(self, scene):
        self.scene = scene
        self.undo_stack = []
        self.redo_stack = []
        self.last_error = None

    def execute(self, cmd):
        try:
            cmd.do(self.scene)
        except Exception as exc:  # the host also swallows and reports
            self.last_error = f"{type(exc).__name__}: {exc}"
            return
        self.last_error = None
        self.undo_stack.append(cmd)
        self.redo_stack.clear()

    def undo(self):
        if not self.undo_stack:
            return False
        cmd = self.undo_stack.pop()
        cmd.undo(self.scene)
        self.redo_stack.append(cmd)
        return True

    def redo(self):
        if not self.redo_stack:
            return False
        cmd = self.redo_stack.pop()
        cmd.do(self.scene)
        self.undo_stack.append(cmd)
        return True


class InsertGroupCommand(Command):
    def __init__(self, group):
        self.group = group

    def do(self, scene):
        scene.groups.append(self.group)
        scene.selection.clear()
        scene.selection.add(self.group)
        scene.version += 1

    def undo(self, scene):
        if self.group in scene.groups:
            scene.groups.remove(self.group)
        scene.selection.discard(self.group)
        scene.version += 1


class CompoundCommand(Command):
    def __init__(self, commands):
        self.commands = list(commands)

    def do(self, scene):
        done = []
        try:
            for c in self.commands:
                c.do(scene)
                done.append(c)
        except CommandRejected:
            for c in reversed(done):
                c.undo(scene)
            raise

    def undo(self, scene):
        for c in reversed(self.commands):
            c.undo(scene)


class AssignLayerCommand(Command):
    def __init__(self, entities, layer):
        self._entities = list(entities)
        self._layer = layer
        self._prev = []
        self._created = False

    def do(self, scene):
        from core.layers import Layer, assign_layer, layer_of
        if scene.layer(self._layer) is None:
            scene.layers.append(Layer(self._layer))
            self._created = True
        self._prev = [layer_of(e) for e in self._entities]
        for e in self._entities:
            assign_layer(e, self._layer)
        scene.version += 1

    def undo(self, scene):
        from core.layers import assign_layer
        for e, prev in zip(self._entities, self._prev):
            assign_layer(e, prev)
        if self._created:
            ly = scene.layer(self._layer)
            if ly is not None:
                scene.layers.remove(ly)
        scene.version += 1
```

```python
# SPDX-License-Identifier: GPL-3.0-or-later
"""Just enough of core.units: a settable model unit and two formatters."""
_UNIT = {"length": "m", "precision": 2}
IN_M = 0.0254


def set_model_unit(code, precision=2):
    _UNIT["length"], _UNIT["precision"] = code, precision


def model_unit():
    return _UNIT["length"]


def model_precision():
    return _UNIT["precision"]


def format_length(metres, units="m", decimals=2):
    if units in ("ft-in", "ft-in-frac"):
        inches = metres / IN_M
        feet = int(inches // 12)
        rest = inches - feet * 12
        return f"{feet}' {rest:.{decimals}f}\""
    if units in ("in", "in-frac"):
        return f"{metres / IN_M:.{decimals}f}\""
    if units == "ft":
        return f"{metres / IN_M / 12:.{decimals}f}'"
    if units == "mm":
        return f"{metres * 1000:.{decimals}f} mm"
    if units == "cm":
        return f"{metres * 100:.{decimals}f} cm"
    return f"{metres:.{decimals}f} m"


def fmt_len(metres):
    return format_length(float(metres), model_unit(), model_precision())
```

```python
# SPDX-License-Identifier: GPL-3.0-or-later
"""Convert the AISC Shapes Database v16.0 workbook into igz_steel/data/aisc_v16.json.

Developer tool, needs openpyxl. Usage:
    python devtools/build_db.py "aisc-shapes-database-v160-2.xlsx" igz_steel/data/aisc_v16.json
"""
from __future__ import annotations

import json
import re
import sys
from datetime import date
from pathlib import Path

SHEET = "Database v16.0"
FAMILIES = ["W", "M", "S", "HP", "C", "MC", "L", "WT", "MT", "ST", "2L", "HSS", "PIPE"]
GEOM = ["d", "bf", "tw", "tf", "kdes", "k1", "t", "b", "Ht", "B", "OD", "tdes", "x", "y"]
MISSING = {"–", "-", "—", "", None}

_FRAC = re.compile(r"^(\d+)(?:-(\d+)/(\d+))?$|^(\d+)/(\d+)$")


def frac_to_float(token: str) -> float:
    """'1-3/8' -> 1.375, '3/4' -> 0.75, '12' -> 12.0, '1.5' -> 1.5."""
    token = token.strip()
    try:
        return float(token)
    except ValueError:
        pass
    m = _FRAC.match(token)
    if m is None:
        raise ValueError(f"not a fraction: {token!r}")
    if m.group(1) is not None:
        whole = float(m.group(1))
        if m.group(2):
            whole += float(m.group(2)) / float(m.group(3))
        return whole
    return float(m.group(4)) / float(m.group(5))


def parse_2l(label: str):
    """'2L8X4X1X3/4LLBB' -> (leg1, leg2, t, gap, llbb); llbb is None for equal legs."""
    if not label.startswith("2L"):
        raise ValueError(label)
    s = label[2:]
    llbb = None
    for tok, value in (("LLBB", True), ("SLBB", False)):
        if s.endswith(tok):
            llbb = value
            s = s[: -len(tok)]
    parts = s.split("X")
    if len(parts) not in (3, 4):
        raise ValueError(f"unexpected 2L label {label!r}")
    try:
        leg1, leg2, t = (frac_to_float(p) for p in parts[:3])
        gap = frac_to_float(parts[3]) if len(parts) == 4 else 0.0
    except ValueError as exc:
        raise ValueError(f"unexpected 2L label {label!r}: {exc}") from None
    return leg1, leg2, t, gap, llbb


def _num(value):
    if value in MISSING:
        return None
    if isinstance(value, (int, float)):
        return float(value)
    try:
        return float(str(value).strip())
    except ValueError:
        return None


def _block(header, start, names):
    """Column index of each name inside one unit block of the header row."""
    idx = {}
    for i in range(start, len(header)):
        h = header[i]
        if h in names and h not in idx:
            idx[h] = i
    missing = [n for n in names if n not in idx]
    if missing:
        raise SystemExit(f"header mismatch, missing {missing} from column {start}")
    return idx


def convert(xlsx: Path) -> dict:
    import openpyxl
    wb = openpyxl.load_workbook(xlsx, read_only=True)
    ws = wb[SHEET]
    rows = ws.iter_rows(values_only=True)
    header = [str(h).strip() if h is not None else "" for h in next(rows)]
    second = header.index("EDI_Std_Nomenclature", 2)   # start of the metric block
    names = ["Type", "EDI_Std_Nomenclature", "AISC_Manual_Label", "T_F", "W", "A"] + GEOM
    imp = _block(header, 0, names)
    met = _block(header, second, ["EDI_Std_Nomenclature", "AISC_Manual_Label", "W", "A"] + GEOM)
    shapes = []
    for row in rows:
        fam = row[imp["Type"]]
        if fam not in FAMILIES:
            continue
        label = str(row[imp["AISC_Manual_Label"]]).strip()
        dims = {k: _num(row[imp[k]]) for k in GEOM}
        dims_mm = {k: _num(row[met[k]]) for k in GEOM}
        dims = {k: v for k, v in dims.items() if v is not None}
        dims_mm = {k: v for k, v in dims_mm.items() if v is not None}
        llbb = None
        if fam == "2L":
            _l1, _l2, _t, gap, llbb = parse_2l(label)
            dims["gap"] = gap
            dims_mm["gap"] = round(gap * 25.4, 4)
        note = row[imp["T_F"]]
        shapes.append({
            "family": fam,
            "label": label,
            "label_metric": str(row[met["AISC_Manual_Label"]]).strip(),
            "edi": str(row[imp["EDI_Std_Nomenclature"]]).strip(),
            "round": fam in ("HSS", "PIPE") and "OD" in dims,
            "llbb": llbb,
            "dims": dims,
            "dims_mm": dims_mm,
            "W": _num(row[imp["W"]]),
            "A": _num(row[imp["A"]]),
            "W_kgm": _num(row[met["W"]]),
            "A_mm2": _num(row[met["A"]]),
            "notes": "sloped flanges" if (fam in ("M", "MT") and note == "T") else "",
        })
    if len(shapes) != 2299:
        raise SystemExit(f"expected 2299 shapes, got {len(shapes)}")
    return {"source": "AISC Shapes Database v16.0 (August 2023)",
            "generated": date.today().isoformat(), "shapes": shapes}


def main(argv):
    if len(argv) != 3:
        raise SystemExit(__doc__)
    out = Path(argv[2])
    out.parent.mkdir(parents=True, exist_ok=True)
    data = convert(Path(argv[1]))
    out.write_text(json.dumps(data, separators=(",", ":"), ensure_ascii=True), encoding="utf-8")
    print(f"wrote {out} ({out.stat().st_size // 1024} KB, {len(data['shapes'])} shapes)")


if __name__ == "__main__":
    main(sys.argv)
```

```python
# SPDX-License-Identifier: GPL-3.0-or-later
"""The AISC shape table: loaded once from data/aisc_v16.json. Pure Python."""
from __future__ import annotations

import json
from dataclasses import dataclass
from pathlib import Path

IN_M = 0.0254
LB_PER_FT_TO_KG_PER_M = 1.48816394
FAMILIES = ["W", "M", "S", "HP", "C", "MC", "L", "WT", "MT", "ST", "2L", "HSS", "PIPE"]
DATA_PATH = Path(__file__).parent / "data" / "aisc_v16.json"


@dataclass(frozen=True)
class Shape:
    family: str
    label: str
    label_metric: str
    edi: str
    round: bool
    llbb: object          # True / False / None
    dims: dict            # inches
    dims_mm: dict         # millimetres
    W: float              # lb/ft
    A: float              # in^2
    W_kgm: float
    A_mm2: float
    notes: str

    def dims_m(self) -> dict:
        out = {k: v * IN_M for k, v in self.dims.items()}
        if self.family == "2L":
            out["llbb"] = True if self.llbb is None else bool(self.llbb)
        return out

    def weight_per_m(self) -> float:
        if self.W_kgm is not None:
            return float(self.W_kgm)
        return float(self.W or 0.0) * LB_PER_FT_TO_KG_PER_M

    def weight_per_ft(self) -> float:
        return float(self.W or 0.0)

    def label_for(self, unit_system: str) -> str:
        return self.label_metric if unit_system == "metric" else self.label


class Database:
    def __init__(self, shapes):
        self._shapes = list(shapes)
        self._by_family = {f: [] for f in FAMILIES}
        self._by_label = {}
        for s in self._shapes:
            self._by_family[s.family].append(s)
            self._by_label[s.label.lower()] = s
            self._by_label.setdefault(s.label_metric.lower(), s)

    def families(self):
        return list(FAMILIES)

    def shapes(self, family):
        return list(self._by_family.get(family, ()))

    def find(self, label):
        return self._by_label.get(str(label).strip().lower())

    def search(self, text, family=None):
        needle = str(text).strip().lower()
        pool = self.shapes(family) if family else self._shapes
        return [s for s in pool
                if needle in s.label.lower() or needle in s.label_metric.lower()]


_DB = None


def load(path=DATA_PATH) -> Database:
    global _DB
    if path != DATA_PATH:
        with open(path, "r", encoding="utf-8") as fh:
            return Database(Shape(**e) for e in json.load(fh)["shapes"])
    if _DB is None:
        with open(DATA_PATH, "r", encoding="utf-8") as fh:
            _DB = Database(Shape(**e) for e in json.load(fh)["shapes"])
    return _DB
```

```python
# SPDX-License-Identifier: GPL-3.0-or-later
"""Cross-section outlines of AISC shapes. Pure Python, metres, tuples.

Coordinates: ``u`` across the section (horizontal), ``v`` along the web
(vertical, +v up). Every finished profile is centred on its centroid.
Outer loops run counter-clockwise, holes clockwise.
"""
from __future__ import annotations

import math
from dataclasses import dataclass, field

ARC_SEGMENTS = 4
MIN_ROUND_SEGMENTS = 8
MAX_ROUND_SEGMENTS = 96
DEFAULT_ROUND_SEGMENTS = 24


@dataclass
class Loop:
    points: list                      # [(u, v)], closed implicitly
    arc_edges: set = field(default_factory=set)   # edge i: points[i] -> points[i+1]


@dataclass
class Region:
    outer: Loop                       # counter-clockwise
    holes: list                       # [Loop], clockwise


@dataclass
class InsertionPoint:
    id: str
    label: str
    uv: tuple


@dataclass
class Profile:
    regions: list                     # [Region]
    points: list                      # [InsertionPoint]
    centroid: tuple                   # always (0.0, 0.0) after centring
    area: float                       # m^2
    bbox: tuple                       # (umin, vmin, umax, vmax)

    def point(self, insertion_id):
        for p in self.points:
            if p.id == insertion_id:
                return p
        return self.points[0]


# ---------------------------------------------------------------- helpers

def _unit(v):
    n = math.hypot(v[0], v[1])
    return (v[0] / n, v[1] / n) if n > 0 else (0.0, 0.0)


def signed_area(pts):
    a = 0.0
    n = len(pts)
    for i in range(n):
        x0, y0 = pts[i]
        x1, y1 = pts[(i + 1) % n]
        a += x0 * y1 - x1 * y0
    return a / 2.0


def polygon_centroid(pts):
    a = signed_area(pts)
    if abs(a) < 1e-18:
        n = len(pts)
        return (sum(p[0] for p in pts) / n, sum(p[1] for p in pts) / n)
    cx = cy = 0.0
    n = len(pts)
    for i in range(n):
        x0, y0 = pts[i]
        x1, y1 = pts[(i + 1) % n]
        w = x0 * y1 - x1 * y0
        cx += (x0 + x1) * w
        cy += (y0 + y1) * w
    return (cx / (6.0 * a), cy / (6.0 * a))


def round_corners(corners, segs=ARC_SEGMENTS):
    """Replace every corner ``(u, v, r)`` with ``r > 0`` by a tangent arc of
    ``segs`` segments. Works for convex and concave corners alike. A fillet
    that would not fit between its neighbours is skipped (sharp corner)."""
    n = len(corners)
    pts = []
    arc_edges = set()
    for i, (u, v, r) in enumerate(corners):
        if r <= 0.0:
            pts.append((u, v))
            continue
        pu, pv, _ = corners[i - 1]
        nu, nv, _ = corners[(i + 1) % n]
        d1 = _unit((pu - u, pv - v))
        d2 = _unit((nu - u, nv - v))
        cos_t = max(-1.0, min(1.0, d1[0] * d2[0] + d1[1] * d2[1]))
        theta = math.acos(cos_t)
        if theta < 1e-6 or abs(theta - math.pi) < 1e-6:
            pts.append((u, v))
            continue
        tdist = r / math.tan(theta / 2.0)
        if (tdist > 0.5 * math.hypot(pu - u, pv - v) + 1e-12
                or tdist > 0.5 * math.hypot(nu - u, nv - v) + 1e-12):
            pts.append((u, v))
            continue
        t1 = (u + d1[0] * tdist, v + d1[1] * tdist)
        t2 = (u + d2[0] * tdist, v + d2[1] * tdist)
        bis = _unit((d1[0] + d2[0], d1[1] + d2[1]))
        cdist = r / math.sin(theta / 2.0)
        c = (u + bis[0] * cdist, v + bis[1] * cdist)
        a1 = math.atan2(t1[1] - c[1], t1[0] - c[0])
        a2 = math.atan2(t2[1] - c[1], t2[0] - c[0])
        sweep = a2 - a1
        while sweep > math.pi:
            sweep -= 2.0 * math.pi
        while sweep < -math.pi:
            sweep += 2.0 * math.pi
        first = len(pts)
        for k in range(segs + 1):
            a = a1 + sweep * k / segs
            pts.append((c[0] + r * math.cos(a), c[1] + r * math.sin(a)))
        arc_edges.update(range(first, first + segs))
    return Loop(pts, arc_edges)


def reverse_loop(loop):
    n = len(loop.points)
    pts = list(reversed(loop.points))
    arcs = {(n - 2 - i) % n for i in loop.arc_edges}
    return Loop(pts, arcs)


def circle_loop(r, segments):
    segments = max(MIN_ROUND_SEGMENTS, min(MAX_ROUND_SEGMENTS, int(segments)))
    pts = [(r * math.cos(2.0 * math.pi * k / segments),
            r * math.sin(2.0 * math.pi * k / segments)) for k in range(segments)]
    return Loop(pts, set(range(segments)))
```

```python
def _fillet_radius(dims, key_thickness, fillets):
    if not fillets:
        return 0.0
    k = dims.get("kdes")
    t = dims.get(key_thickness)
    if k is None or t is None:
        return 0.0
    return max(0.0, k - t)


def _i_shape(dims, fillets):
    d, bf, tw, tf = dims["d"], dims["bf"], dims["tw"], dims["tf"]
    r = _fillet_radius(dims, "tf", fillets)
    hb, hd, hw = bf / 2.0, d / 2.0, tw / 2.0
    outer = [(-hb, -hd, 0), (hb, -hd, 0), (hb, -hd + tf, 0), (hw, -hd + tf, r),
             (hw, hd - tf, r), (hb, hd - tf, 0), (hb, hd, 0), (-hb, hd, 0),
             (-hb, hd - tf, 0), (-hw, hd - tf, r), (-hw, -hd + tf, r), (-hb, -hd + tf, 0)]
    return [(outer, [])]


def _channel(dims, fillets):
    d, bf, tw, tf = dims["d"], dims["bf"], dims["tw"], dims["tf"]
    r = _fillet_radius(dims, "tf", fillets)
    outer = [(0, 0, 0), (bf, 0, 0), (bf, tf, 0), (tw, tf, r),
             (tw, d - tf, r), (bf, d - tf, 0), (bf, d, 0), (0, d, 0)]
    return [(outer, [])]

             (hb, d, 0), (-hb, d, 0), (-hb, d - tf, 0), (-hw, d - tf, r)]
    return [(outer, [])]

def _close(a, b, eps=1e-9):
    return abs(a[0] - b[0]) <= eps and abs(a[1] - b[1]) <= eps


def _assemble(raw_regions, segs=ARC_SEGMENTS):
    """Round the corners, build the loops, centre on the centroid and derive
    the insertion points from the SHARP corners (so ids never depend on the
    fillet setting)."""
    regions = []
    sharp_all = []
    area = 0.0
    cx = cy = 0.0
    for outer_corners, hole_corner_lists in raw_regions:
        outer = round_corners(outer_corners, segs)
        a = signed_area(outer.points)
        c = polygon_centroid(outer.points)
        area += a
        cx += a * c[0]
        cy += a * c[1]
        holes = []
        for hc in hole_corner_lists:
            h = round_corners(hc, segs)
            ha = signed_area(h.points)
            hcen = polygon_centroid(h.points)
            area -= ha
            cx -= ha * hcen[0]
            cy -= ha * hcen[1]
            holes.append(reverse_loop(h))
        regions.append(Region(outer, holes))
        sharp_all.append([(u, v) for (u, v, _r) in outer_corners])
    cx, cy = (cx / area, cy / area) if area > 0 else (0.0, 0.0)

    def shift(p):
        return (p[0] - cx, p[1] - cy)

    for reg in regions:
        reg.outer.points = [shift(p) for p in reg.outer.points]
        for h in reg.holes:
            h.points = [shift(p) for p in h.points]
    us = [p[0] for reg in regions for p in reg.outer.points]
    vs = [p[1] for reg in regions for p in reg.outer.points]
    bbox = (min(us), min(vs), max(us), max(vs))
    umin, vmin, umax, vmax = bbox
    named_uv = {"top": (0.0, vmax), "bottom": (0.0, vmin), "left": (umin, 0.0),
                "right": (umax, 0.0), "top_left": (umin, vmax), "top_right": (umax, vmax),
                "bottom_left": (umin, vmin), "bottom_right": (umax, vmin)}
    points = [InsertionPoint("centroid", "Centroid", (0.0, 0.0))]
    points += [InsertionPoint(i, label, named_uv[i]) for i, label in NAMED]
    k = 0
    vertices = []
    midpoints = []
    for sharp in sharp_all:
        n = len(sharp)
        for i in range(n):
            a = shift(sharp[i])
            b = shift(sharp[(i + 1) % n])
            vertices.append((f"v{k}", a))
            midpoints.append((f"m{k}", ((a[0] + b[0]) / 2.0, (a[1] + b[1]) / 2.0)))
            k += 1
    for ident, uv in vertices + midpoints:
        if any(_close(uv, p.uv) for p in points):
            continue
        points.append(InsertionPoint(ident, ident, uv))
    return Profile(regions, points, (0.0, 0.0), area, bbox)


def build_profile(family, dims, fillets=True, segments=DEFAULT_ROUND_SEGMENTS):
    builder = _BUILDERS.get(family)
    if builder is None:
        raise ValueError(f"unknown shape family {family!r}")
    return _assemble(builder(dims, fillets))
```

```python
                b = tuple(round(c, 9) for c in loop[(i + 1) % n])
                counts[frozenset((a, b))] += 1
    return counts

    p0, p1, p2 = face[0], face[1], face[2]

    v = (p2[0] - p0[0], p2[1] - p0[1], p2[2] - p0[2])
    return (u[1] * v[2] - u[2] * v[1], u[2] * v[0] - u[0] * v[2], u[0] * v[1] - u[1] * v[0])
```

```python
# SPDX-License-Identifier: GPL-3.0-or-later
"""Members from profiles: extrusion along local +X, the world frame, IFC class.

Pure Python on tuples. The profile's (u, v) maps to local (y, z); the member
runs from x = 0 to x = length; the insertion point sits on the local origin.
"""
from __future__ import annotations

import math
from dataclasses import dataclass, field

MIN_LENGTH = 0.001
MAX_LENGTH = 1000.0


@dataclass
class MemberMesh:
    faces: list = field(default_factory=list)
    soft_pairs: set = field(default_factory=set)


# ------------------------------------------------------------ vectors

def add(a, b):
    return (a[0] + b[0], a[1] + b[1], a[2] + b[2])


def sub(a, b):
    return (a[0] - b[0], a[1] - b[1], a[2] - b[2])


def scale(a, s):
    return (a[0] * s, a[1] * s, a[2] * s)


def dot(a, b):
    return a[0] * b[0] + a[1] * b[1] + a[2] * b[2]


def cross(a, b):
    return (a[1] * b[2] - a[2] * b[1], a[2] * b[0] - a[0] * b[2], a[0] * b[1] - a[1] * b[0])


def norm(a):
    return math.sqrt(dot(a, a))


def unit(a):
    n = norm(a)
    return scale(a, 1.0 / n) if n > 0 else (0.0, 0.0, 0.0)


def direction_and_length(a, b):
    d = sub(b, a)
    n = norm(d)
    if n < 1e-12:
        return None, 0.0
    return scale(d, 1.0 / n), n


def member_end(start, direction, length):
    return add(start, scale(unit(direction), length))


# ------------------------------------------------------------ extrusion

def extrude(profile, length, insertion_uv):
    ou, ov = insertion_uv
    L = float(length)

    def P(uv, x):
        return (x, uv[0] - ou, uv[1] - ov)

    faces = []
    soft = set()
    if L < MIN_LENGTH:
        for reg in profile.regions:
            outer = [P(p, 0.0) for p in reg.outer.points]
            holes = [[P(p, 0.0) for p in h.points] for h in reg.holes]
            faces.append((outer, holes) if holes else outer)
        return MemberMesh(faces, soft)
    for reg in profile.regions:
        outer0 = [P(p, 0.0) for p in reversed(reg.outer.points)]
        holes0 = [[P(p, 0.0) for p in reversed(h.points)] for h in reg.holes]
        faces.append((outer0, holes0) if holes0 else outer0)
        outerL = [P(p, L) for p in reg.outer.points]
        holesL = [[P(p, L) for p in h.points] for h in reg.holes]
        faces.append((outerL, holesL) if holesL else outerL)
    for reg in profile.regions:
        for loop in (reg.outer, *reg.holes):
            pts = loop.points
            n = len(pts)
            idx = []
            for i in range(n):
                a, b = pts[i], pts[(i + 1) % n]
                faces.append([P(a, 0.0), P(b, 0.0), P(b, L), P(a, L)])
                idx.append(len(faces) - 1)
            for i in range(n):
                if i in loop.arc_edges or (i - 1) % n in loop.arc_edges:
                    soft.add((idx[(i - 1) % n], idx[i]))
    return MemberMesh(faces, soft)


# ------------------------------------------------------------ frame

def member_matrix(start, direction, roll_deg=0.0):
    x = unit(direction)
    vertical = abs(x[2]) > math.cos(math.radians(1.0))
    ref = (0.0, 1.0, 0.0) if vertical else (0.0, 0.0, 1.0)
    z = unit(sub(ref, scale(x, dot(ref, x))))
    y = cross(z, x)
    if roll_deg:
        a = math.radians(roll_deg)
        c, s = math.cos(a), math.sin(a)
        y, z = add(scale(y, c), scale(z, s)), add(scale(z, c), scale(y, -s))
    return [x[0], y[0], z[0], float(start[0]),
            x[1], y[1], z[1], float(start[1]),
            x[2], y[2], z[2], float(start[2]),
            0.0, 0.0, 0.0, 1.0]


def apply_matrix(m, p):
    return (m[0] * p[0] + m[1] * p[1] + m[2] * p[2] + m[3],
            m[4] * p[0] + m[5] * p[1] + m[6] * p[2] + m[7],
            m[8] * p[0] + m[9] * p[1] + m[10] * p[2] + m[11])


def ifc_class_for(direction, tol_deg=5.0):
    x = unit(direction)
    vz = abs(x[2])
    if vz >= math.cos(math.radians(tol_deg)):
        return "IfcColumn"
    if vz <= math.sin(math.radians(tol_deg)):
        return "IfcBeam"
    return "IfcMember"


# ------------------------------------------------------------ preview

def preview_segments(profile, insertion_uv, start, direction, length, roll_deg=0.0):
    """Wireframe of the member: both end outlines and one longitudinal line per
    vertex (zero length: the single outline). World coordinates."""
    m = member_matrix(start, direction, roll_deg)
    ou, ov = insertion_uv
    L = float(length)
    ends = [0.0] if L < MIN_LENGTH else [0.0, L]
    segs = []
    for reg in profile.regions:
        for loop in (reg.outer, *reg.holes):
            pts = loop.points
            n = len(pts)
            world = {}
            for x in ends:
                world[x] = [apply_matrix(m, (x, p[0] - ou, p[1] - ov)) for p in pts]
                for i in range(n):
                    segs.append((world[x][i], world[x][(i + 1) % n]))
            if len(ends) == 2:
                for i in range(n):
                    segs.append((world[0.0][i], world[L][i]))
    return segs
```

```python
# SPDX-License-Identifier: GPL-3.0-or-later
"""Thin wrapper over IngeTrazo's core.units with safe fallbacks."""
from __future__ import annotations

IMPERIAL_UNITS = {"in", "ft", "ft-in", "in-frac", "ft-in-frac"}
KG_TO_LB = 2.2046226218


def model_unit_code() -> str:
    try:
        from core.units import model_unit
        return str(model_unit())
    except Exception:
        return "m"


def is_imperial() -> bool:
    return model_unit_code() in IMPERIAL_UNITS


def fmt_len(metres: float) -> str:
    try:
        from core.units import fmt_len as host_fmt
        return host_fmt(float(metres))
    except Exception:
        return f"{float(metres):.3f} m"


def fmt_weight(kg: float) -> str:
    if is_imperial():
        return f"{float(kg) * KG_TO_LB:,.1f} lb"
    return f"{float(kg):,.1f} kg"


def fmt_dim(value: float, unit_system: str) -> str:
    """A tabulated dimension for the dialog: inches or millimetres."""
    if unit_system == "metric":
        return f"{float(value):.1f} mm"
    return f"{float(value):.3f} in"
```

```python
# SPDX-License-Identifier: GPL-3.0-or-later
"""Bill of Materials arithmetic. Pure Python; formatting is injected."""
from __future__ import annotations

import csv
import io
from dataclasses import dataclass

from ._db import FAMILIES
from ._geometry import MIN_LENGTH


@dataclass
class Row:
    mark: str
    label: str
    family: str
    length_m: float
    weight_kg: float
    layer: str
    ifc_class: str
    uid: object
    is_profile: bool


@dataclass
class SummaryRow:
    label: str
    family: str
    count: int
    total_length_m: float
    total_weight_kg: float


@dataclass
class BOM:
    rows: list
    summary: list
    count: int
    total_length_m: float
    total_weight_kg: float


def collect(records) -> BOM:
    rows = []
    counters = {}
    totals = {}
    for rec in records:
        label = str(rec["label"])
        counters[label] = counters.get(label, 0) + 1
        length = float(rec.get("length_m") or 0.0)
        is_profile = length < MIN_LENGTH
        weight = 0.0 if is_profile else length * float(rec.get("weight_per_m") or 0.0)
        rows.append(Row(f"{label}-{counters[label]}", label, str(rec.get("family", "")),
                        length, weight, str(rec.get("layer") or "Layer 0"),
                        str(rec.get("ifc_class") or ""), rec.get("uid"), is_profile))
        if not is_profile:
            t = totals.setdefault(label, [rec.get("family", ""), 0, 0.0, 0.0])
            t[1] += 1
            t[2] += length
            t[3] += weight
    order = {f: i for i, f in enumerate(FAMILIES)}
    summary = [SummaryRow(label, fam, n, L, w) for label, (fam, n, L, w) in totals.items()]
    summary.sort(key=lambda s: (order.get(s.family, 99), s.label))
    return BOM(rows, summary, sum(s.count for s in summary),
               sum(s.total_length_m for s in summary), sum(s.total_weight_kg for s in summary))


def to_csv(bom: BOM, fmt_len, fmt_weight) -> str:
    out = io.StringIO()
    w = csv.writer(out, lineterminator="\n")
    w.writerow(["mark", "label", "family", "length", "weight", "layer", "ifc_class",
                "length_m", "weight_kg"])
    for r in bom.rows:
        w.writerow([r.mark, r.label, r.family, fmt_len(r.length_m), fmt_weight(r.weight_kg),
                    r.layer, r.ifc_class, round(r.length_m, 4), round(r.weight_kg, 2)])
    w.writerow([])
    w.writerow(["label", "family", "count", "total_length", "total_weight",
                "total_length_m", "total_weight_kg"])
    for s in bom.summary:
        w.writerow([s.label, s.family, s.count, fmt_len(s.total_length_m),
                    fmt_weight(s.total_weight_kg), round(s.total_length_m, 4),
                    round(s.total_weight_kg, 2)])
    w.writerow(["TOTAL", "", bom.count, fmt_len(bom.total_length_m),
                fmt_weight(bom.total_weight_kg), round(bom.total_length_m, 4),
                round(bom.total_weight_kg, 2)])
    return out.getvalue()
```

```python
from __future__ import annotations

import copy
import logging

from PySide6.QtGui import QMatrix4x4, QVector3D

from . import EXT_VERSION, KEY
from ._geometry import (MIN_LENGTH, apply_matrix, extrude, ifc_class_for, member_matrix,
                        unit)
from ._profiles import build_profile

log = logging.getLogger("ingetrazo.plugins.igz_steel")

_PROFILE_CACHE = {}


# ------------------------------------------------------------ parameters

def is_steel_group(group) -> bool:
    ext = getattr(group, "ext", None)
    block = ext.get(KEY) if isinstance(ext, dict) else None
    return (isinstance(block, dict) and "label" in block
            and getattr(group, "xform", None) is not None)


def member_params(group):
    ext = getattr(group, "ext", None)
    block = ext.get(KEY) if isinstance(ext, dict) else None
    if not isinstance(block, dict) or "label" not in block:
        return None
    return copy.deepcopy(block)


def new_params(label, unit_system, insertion, roll, fillets, segments) -> dict:
    return {"version": EXT_VERSION, "label": str(label), "unit_system": str(unit_system),
            "insertion": str(insertion), "roll": float(roll), "fillets": bool(fillets),
            "segments": int(segments)}


# ------------------------------------------------------------ geometry

def profile_for(shape, params):
    key = (shape.label, bool(params.get("fillets", True)), int(params.get("segments", 24)))
    prof = _PROFILE_CACHE.get(key)
    if prof is None:
        prof = build_profile(shape.family, shape.dims_m(), fillets=key[1], segments=key[2])
        _PROFILE_CACHE[key] = prof
    return prof


def insertion_uv(profile, insertion_id):
    for p in profile.points:
        if p.id == insertion_id:
            return p.uv
    return (0.0, 0.0)


def _qv(p):
    return QVector3D(float(p[0]), float(p[1]), float(p[2]))


def build_mesh(member_mesh):
    from core.mesh import Mesh
    mesh = Mesh()
    for face in member_mesh.faces:
        if isinstance(face, tuple):
            outer, holes = face
            mesh.add_face([_qv(p) for p in outer], [[_qv(p) for p in h] for h in holes] or None)
        else:
            mesh.add_face([_qv(p) for p in face])
    try:
        from core.orient import orient_outward
        orient_outward(mesh)
    except Exception:
        log.exception("igz_steel: orient_outward failed")
    if member_mesh.soft_pairs:
        index = {id(f): i for i, f in enumerate(mesh.faces)}
        for edge in mesh.edges:
            if len(edge.faces) != 2:
                continue
            i, j = index.get(id(edge.faces[0])), index.get(id(edge.faces[1]))
            if (i, j) in member_mesh.soft_pairs or (j, i) in member_mesh.soft_pairs:
                edge.soft = True
    return mesh


def member_parts(shape, params, start, direction, length) -> dict:
    length = float(length)
    direction = unit(direction) if length >= MIN_LENGTH else (1.0, 0.0, 0.0)
    if length < MIN_LENGTH:
        length = 0.0
    profile = profile_for(shape, params)
    uv = insertion_uv(profile, params.get("insertion", "centroid"))
    mm = extrude(profile, length, uv)
    rows = member_matrix(start, direction, float(params.get("roll", 0.0)))
    ext_block = dict(params)
    ext_block.update({"version": EXT_VERSION, "start": [float(c) for c in start],
                      "direction": [float(c) for c in direction], "length": length})
    name = shape.label if length > 0 else f"{shape.label} (profile)"
    ifc = {"class": ifc_class_for(direction) if length > 0 else "IfcMember", "name": shape.label}
    return {"mesh": build_mesh(mm), "xform": QMatrix4x4(*rows), "name": name,
            "ifc": ifc, "ext": {KEY: ext_block}, "length": length}


def make_group(parts, layer=None):
    from core.group import Group
    g = Group(mesh=parts["mesh"], name=parts["name"])
    g.xform = parts["xform"]
    g.component = False
    g.ifc = dict(parts["ifc"])
    g.ext = copy.deepcopy(parts["ext"])
    if layer:
        g.layer = layer
    return g


# ------------------------------------------------------------ commands

def _command_base():
    from core.history import Command
    return Command


class RebuildMemberCommand(_command_base()):
    """Swap a member's mesh, pose and parameters in place; undo puts them back."""

    def __init__(self, group, parts):
        self.group = group
        self.parts = parts
        self._before = None

    def _apply(self, scene, mesh, xform, name, ifc, ext):
        g = self.group
        g.mesh, g.xform, g.name = mesh, xform, name
        g.ifc = copy.deepcopy(ifc)
        g.ext = copy.deepcopy(ext)
        try:
            from core.history import _dirty_group_chunks
            _dirty_group_chunks(scene)
        except Exception:
            pass
        sel = getattr(scene, "selection", None)
        if sel is not None:
            sel.clear()
            sel.add(g)
        scene.version += 1

    def do(self, scene):
        g = self.group
        if self._before is None:
            self._before = (g.mesh, g.xform, g.name, copy.deepcopy(g.ifc), copy.deepcopy(g.ext))
        p = self.parts
        self._apply(scene, p["mesh"], p["xform"], p["name"], p["ifc"], p["ext"])

    def undo(self, scene):
        self._apply(scene, *self._before)


def insert_command(group, layer=None):
    from core.history import AssignLayerCommand, CompoundCommand, InsertGroupCommand
    cmds = [InsertGroupCommand(group)]
    if layer:
        cmds.append(AssignLayerCommand([group], layer))
    return CompoundCommand(cmds)


def rebuild_command(group, parts, layer=None):
    from core.history import AssignLayerCommand, CompoundCommand
    from core.layers import layer_of
    cmds = [RebuildMemberCommand(group, parts)]
    if layer and layer_of(group) != layer:
        cmds.append(AssignLayerCommand([group], layer))
    return CompoundCommand(cmds)


def run(viewport, command):
    """Execute through the history; return the error text or None."""
    history = viewport.history
    history.execute(command)
    err = getattr(history, "last_error", None)
    if err:
        return str(err)
    notify = getattr(viewport, "notify_scene_changed", None)
    if callable(notify):
        notify()
    viewport.update()
    return None


# ------------------------------------------------------------ queries

def member_endpoints(group):
    params = member_params(group) or {}
    length = float(params.get("length", 0.0))
    m = group.xform
    a = m.map(QVector3D(0.0, 0.0, 0.0))
    b = m.map(QVector3D(length, 0.0, 0.0))
    return ((a.x(), a.y(), a.z()), (b.x(), b.y(), b.z()))


def member_record(group, db):
    params = member_params(group)
    if params is None:
        return None
    shape = db.find(params.get("label", ""))
    from core.layers import layer_of
    return {"label": params.get("label", ""),
            "family": shape.family if shape else "",
            "length_m": float(params.get("length", 0.0)),
            "weight_per_m": shape.weight_per_m() if shape else 0.0,
            "layer": layer_of(group),
            "ifc_class": (group.ifc or {}).get("class", "") if isinstance(group.ifc, dict) else "",
            "uid": getattr(group, "uid", id(group))}


def iter_groups(scene):
    stack = list(reversed(list(getattr(scene, "groups", []) or [])))
    while stack:
        g = stack.pop()
        yield g
        kids = getattr(g, "children", None) or []
        stack.extend(reversed(list(kids)))
```

```python
def xyz(p):
    if isinstance(p, QVector3D):
        return (float(p.x()), float(p.y()), float(p.z()))
    return (float(p[0]), float(p[1]), float(p[2]))


def _flash(viewport, text, msec=3000):
    fn = getattr(viewport, "flash_status", None)
    if callable(fn):
        try:
            fn(text, msec)
        except Exception:
            pass


def _leave(viewport):
    try:
        viewport.set_active_tool(None)
    except Exception:
        pass


def _as_vectors(segments):
    return [(QVector3D(*a), QVector3D(*b)) for a, b in segments]


def _valid_length(length):
    return MIN_LENGTH <= length <= MAX_LENGTH


class PlaceMemberTool(Tool):
    name = "Place steel member"
    description = "Place an AISC steel member: click the start, then click the end or type a length."
    uses_snap = True
    vcb_label = "Length"
    magnetic_axis_deg = 3.0
    screen_axis_px = 9.0

    def __init__(self, shape, params, on_member, on_profile):
        self.shape = shape
        self.params = dict(params)
        self.profile = profile_for(shape, self.params)
        self.uv = insertion_uv(self.profile, self.params.get("insertion", "centroid"))
        self.roll = float(self.params.get("roll", 0.0))
        self.on_member = on_member
        self.on_profile = on_profile
        self.start_point = None
        self.hover = None

    # -- protocol -----------------------------------------------------------
    def on_activate(self, viewport):
        self.start_point = None
        _flash(viewport, f"{self.shape.label}: click to place the profile  •  Esc exits", 3500)

    def on_deactivate(self, viewport):
        self.start_point = None
        self.hover = None

    def on_hover(self, ctx):
        self.hover = xyz(ctx.world)
        ctx.viewport.update()

    def on_click(self, ctx):
        p = xyz(ctx.world)
        if self.start_point is None:
            self.start_point = QVector3D(*p)
            self.hover = p
            _flash(ctx.viewport, f"{self.shape.label}: click the end point or type a length"
                                 "  •  Esc places the profile only", 3500)
            ctx.viewport.update()
            return
        d, length = direction_and_length(xyz(self.start_point), p)
        if d is None or not _valid_length(length):
            return
        self._commit(ctx.viewport, d, length)

    def on_value(self, viewport, value):
        if self.start_point is None:
            return False
        start = xyz(self.start_point)
        if isinstance(value, tuple):
            if len(value) != 3:
                return False
            try:
                d, length = direction_and_length((0.0, 0.0, 0.0), xyz(value))
            except (TypeError, ValueError):
                return False
        else:
            try:
                v = float(value)
            except (TypeError, ValueError):
                return False
            if v == 0.0 or self.hover is None:
                return False
            d, along = direction_and_length(start, self.hover)
            if d is None or along < MIN_LENGTH:
                return False
            length = abs(v)
            if v < 0:
                d = scale(d, -1.0)
        if d is None or not _valid_length(length):
            return False
        return self._commit(viewport, d, length)

    def on_cancel(self, viewport):
        if self.start_point is not None:
            start = xyz(self.start_point)
            self.start_point = None
            if self.on_profile(start):
                _flash(viewport, f"{self.shape.label}: profile placed. Stretch it later.", 3000)
            viewport.update()
            return
        _leave(viewport)

    def status_clause(self):
        if self.start_point is None:
            return f"{self.shape.label}: click  start  •  Esc  exit"
        if self.hover is not None:
            d, length = direction_and_length(xyz(self.start_point), self.hover)
            if d is not None and length >= MIN_LENGTH:
                return (f"{self.shape.label}: {fmt_len(length)}  •  click  end  "
                        f"•  type a length  •  Esc  profile only")
        return f"{self.shape.label}: click  end  •  type a length  •  Esc  profile only"

    def rubber_band_lines(self):
        if self.start_point is None:
            if self.hover is None:
                return []
            return _as_vectors(preview_segments(self.profile, self.uv, self.hover,
                                                (1.0, 0.0, 0.0), 0.0, self.roll))
        start = xyz(self.start_point)
        d, length = (None, 0.0)
        if self.hover is not None:
            d, length = direction_and_length(start, self.hover)
        if d is None or length < MIN_LENGTH:
            return _as_vectors(preview_segments(self.profile, self.uv, start,
                                                (1.0, 0.0, 0.0), 0.0, self.roll))
        return _as_vectors(preview_segments(self.profile, self.uv, start, d, length, self.roll))

    # -- internals ----------------------------------------------------------
    def _commit(self, viewport, direction, length):
        start = xyz(self.start_point)
        ok = bool(self.on_member(start, direction, length))
        if ok:
            self.start_point = None
            _flash(viewport, f"{self.shape.label}: member created ({fmt_len(length)}). "
                             "Click to place another, Esc to exit.", 3000)
        viewport.update()
        return ok
```

```python
def _dist2(a, b):
    d = sub(a, b)
    return dot(d, d)


def _grip_segments(p, size):
    x, y, z = p
    return [((x - size, y, z), (x + size, y, z)),
            ((x, y - size, z), (x, y + size, z)),
            ((x, y, z - size), (x, y, z + size))]


class StretchMemberTool(Tool):
    name = "Stretch steel member"
    description = "Stretch a steel member: click the end to move, then click or type the new length."
    uses_snap = True
    vcb_label = "Length"
    magnetic_axis_deg = 3.0
    screen_axis_px = 9.0

    def __init__(self, group, shape, params, on_commit):
        self.group = group
        self.shape = shape
        self.params = dict(params)
        self.profile = profile_for(shape, self.params)
        self.uv = insertion_uv(self.profile, self.params.get("insertion", "centroid"))
        self.roll = float(self.params.get("roll", 0.0))
        self.on_commit = on_commit
        self.start_point = None          # the fixed end, once a grip is chosen
        self.free = None                 # the end being moved
        self.hover = None
        self.refresh()

    def refresh(self):
        """Re-read the member's ends (after a rebuild, or on construction)."""
        self.p0, self.p1 = member_endpoints(self.group)
        self.axis, self.length = direction_and_length(self.p0, self.p1)
        if self.length < MIN_LENGTH:
            self.axis = None

    # -- protocol -----------------------------------------------------------
    def on_activate(self, viewport):
        self.start_point = None
        _flash(viewport, f"{self.shape.label}: click the end to stretch  •  Esc exits", 3500)

    def on_deactivate(self, viewport):
        self.start_point = None
        self.hover = None

    def on_hover(self, ctx):
        self.hover = xyz(ctx.world)
        ctx.viewport.update()

    def on_click(self, ctx):
        p = xyz(ctx.world)
        if self.start_point is None:
            if self.axis is None:
                fixed, free = self.p0, self.p0
            elif _dist2(p, self.p0) < _dist2(p, self.p1):
                fixed, free = self.p1, self.p0
            else:
                fixed, free = self.p0, self.p1
            self.start_point = QVector3D(*fixed)
            self.free = free
            self.hover = p
            _flash(ctx.viewport, f"{self.shape.label}: click the new end or type a length", 3500)
            ctx.viewport.update()
            return
        d, length = direction_and_length(xyz(self.start_point), self._target(p))
        if d is None or not _valid_length(length):
            return
        self._commit(ctx.viewport, d, length)

    def on_value(self, viewport, value):
        if self.start_point is None or isinstance(value, tuple):
            return False
        try:
            v = float(value)
        except (TypeError, ValueError):
            return False
        if v == 0.0:
            return False
        d = self._axis_from_fixed()
        if d is None:
            if self.hover is None:
                return False
            d, along = direction_and_length(xyz(self.start_point), self.hover)
            if d is None or along < MIN_LENGTH:
                return False
        length = abs(v)
        if v < 0:
            d = scale(d, -1.0)
        if not _valid_length(length):
            return False
        return self._commit(viewport, d, length)

    def on_cancel(self, viewport):
        if self.start_point is not None:
            self.start_point = None
            viewport.update()
            return
        _leave(viewport)

    def status_clause(self):
        if self.start_point is None:
            return f"{self.shape.label}: click  an end to stretch  •  Esc  exit"
        if self.hover is not None:
            d, length = direction_and_length(xyz(self.start_point), self._target(self.hover))
            if d is not None and length >= MIN_LENGTH:
                return f"{self.shape.label}: {fmt_len(length)}  •  click  end  •  type a length"
        return f"{self.shape.label}: click  end  •  type a length  •  Esc  cancel"

    def rubber_band_lines(self):
        size = max(0.05, 0.02 * self.length)
        segs = _grip_segments(self.p0, size)
        if self.length >= MIN_LENGTH:
            segs += _grip_segments(self.p1, size)
        if self.start_point is not None and self.hover is not None:
            fixed = xyz(self.start_point)
            d, length = direction_and_length(fixed, self._target(self.hover))
            if d is not None and length >= MIN_LENGTH:
                segs += preview_segments(self.profile, self.uv, fixed, d, length, self.roll)
        return _as_vectors(segs)

    # -- internals ----------------------------------------------------------
    def _axis_from_fixed(self):
        if self.axis is None or self.start_point is None:
            return None
        d, _ = direction_and_length(xyz(self.start_point), self.free)
        return d or self.axis

    def _target(self, p):
        a = self._axis_from_fixed()
        if a is None:
            return p
        fixed = xyz(self.start_point)
        return add(fixed, scale(a, dot(sub(p, fixed), a)))

    def _commit(self, viewport, direction, length):
        fixed = xyz(self.start_point)
        ok = bool(self.on_commit(fixed, direction, length))
        if ok:
            self.start_point = None
            self.refresh()
            _flash(viewport, f"{self.shape.label}: now {fmt_len(length)}", 3000)
        viewport.update()
        return ok
```

```python
class SectionPreview(QWidget):
    point_picked = Signal(str)
    PICK_PX = 10.0

    def __init__(self, parent=None):
        super().__init__(parent)
        self._profile = None
        self._selected = "centroid"
        self.setMinimumSize(220, 220)

    def set_profile(self, profile):
        self._profile = profile
        if profile is not None and all(p.id != self._selected for p in profile.points):
            self._selected = "centroid"
        self.update()

    def selected(self):
        return self._selected

    def set_selected(self, insertion_id):
        self._selected = insertion_id
        self.update()

    def pick(self, insertion_id):
        self.set_selected(insertion_id)
        self.point_picked.emit(insertion_id)

    def _mapping(self):
        if self._profile is None:
            return None
        umin, vmin, umax, vmax = self._profile.bbox
        w, h = max(umax - umin, 1e-9), max(vmax - vmin, 1e-9)
        margin = 24.0
        sx = (self.width() - 2 * margin) / w
        sy = (self.height() - 2 * margin) / h
        s = min(sx, sy)
        cx, cy = self.width() / 2.0, self.height() / 2.0
        mu, mv = (umin + umax) / 2.0, (vmin + vmax) / 2.0
        return s, cx, cy, mu, mv

    def _to_px(self, uv, mapping):
        s, cx, cy, mu, mv = mapping
        return (cx + (uv[0] - mu) * s, cy - (uv[1] - mv) * s)

    def point_pixel(self, insertion_id):
        mapping = self._mapping()
        return self._to_px(self._profile.point(insertion_id).uv, mapping)

    def pick_at(self, px, py):
        mapping = self._mapping()
        if mapping is None:
            return
        best, best_d = None, self.PICK_PX
        for p in self._profile.points:
            x, y = self._to_px(p.uv, mapping)
            d = math.hypot(x - px, y - py)
            if d <= best_d:
                best, best_d = p.id, d
        if best is not None:
            self.pick(best)

    def mousePressEvent(self, event):
        pos = event.position() if hasattr(event, "position") else event.localPos()
        self.pick_at(pos.x(), pos.y())

    def paintEvent(self, event):
        painter = QPainter(self)
        painter.setRenderHint(QPainter.Antialiasing)
        painter.fillRect(self.rect(), self.palette().base())
        mapping = self._mapping()
        if mapping is None:
            painter.end()
            return
        steel = QColor(120, 130, 145)
        painter.setPen(QPen(steel.darker(140), 1.2))
        painter.setBrush(QBrush(steel.lighter(150)))
        for reg in self._profile.regions:
            poly = QPolygonF([QPointF(*self._to_px(p, mapping)) for p in reg.outer.points])
            painter.drawPolygon(poly)
            painter.setBrush(self.palette().base())
            for h in reg.holes:
                painter.drawPolygon(QPolygonF([QPointF(*self._to_px(p, mapping)) for p in h.points]))
            painter.setBrush(QBrush(steel.lighter(150)))
        for p in self._profile.points:
            x, y = self._to_px(p.uv, mapping)
            if p.id == self._selected:
                painter.setPen(QPen(QColor(200, 40, 40), 2))
                painter.setBrush(QBrush(QColor(255, 120, 120)))
                painter.drawEllipse(QPointF(x, y), 6, 6)
            else:
                painter.setPen(QPen(QColor(30, 90, 200), 1))
                painter.setBrush(QBrush(QColor(120, 170, 255)))
                painter.drawEllipse(QPointF(x, y), 3.5, 3.5)
        painter.end()

        self.layer_combo.setEditable(True)
        form.addRow("Layer", self.layer_combo)

        form.addRow(self.length_label, self.length_spin)

        self.imperial_radio.toggled.connect(lambda _c: self._refill())

        self.shape_list.currentRowChanged.connect(lambda _r: self._on_shape_changed())
        self.fillets_check.toggled.connect(lambda _c: self._on_shape_changed())
        self.segments_spin.valueChanged.connect(lambda _v: self._on_shape_changed())

        self.place_button.clicked.connect(self._on_place)
        self.update_button.clicked.connect(self._on_update)
        close.clicked.connect(self.close)
        self.set_mode("place")

    # -- state --------------------------------------------------------------
    def unit_system(self):
        return "metric" if self.metric_radio.isChecked() else "imperial"

    def set_layers(self, names):
        current = self.layer_combo.currentText()
        self.layer_combo.clear()
        self.layer_combo.addItems(list(names))
        if current:
            self.layer_combo.setEditText(current)

    def set_mode(self, mode):
        self.mode = mode
        editing = mode == "edit"
        self.update_button.setVisible(editing)
        self.place_button.setVisible(not editing)
        self.length_spin.setVisible(editing)
        self.length_label.setVisible(editing)
        self.setWindowTitle("Edit steel member" if editing else "Steel member")

    def current_shape(self):
        item = self.shape_list.currentItem()
        if item is None:
            return None
        return self.db.find(item.data(Qt.UserRole))

    def params(self):
        shape = self.current_shape()
        return {"label": shape.label if shape else None,
                "unit_system": self.unit_system(),
                "insertion": self.preview.selected(),
                "roll": float(self.roll_spin.value()),
                "fillets": bool(self.fillets_check.isChecked()),
                "segments": int(self.segments_spin.value()),
                "layer": self.layer_combo.currentText().strip(),
                "length": float(self.length_spin.value())}

    def load(self, params, layer, length_m):
        shape = self.db.find(params.get("label", ""))
        if shape is None:
            return
        if params.get("unit_system") == "metric":
            self.metric_radio.setChecked(True)
        else:
            self.imperial_radio.setChecked(True)
        self.family_combo.setCurrentText(shape.family)
        self.filter_edit.setText("")
        self._select_label(shape.label)
        self.fillets_check.setChecked(bool(params.get("fillets", True)))
        self.segments_spin.setValue(int(params.get("segments", DEFAULT_ROUND_SEGMENTS)))
        self.roll_spin.setValue(float(params.get("roll", 0.0)))
        self.preview.set_selected(params.get("insertion", "centroid"))
        self._on_point(self.preview.selected())
        self.layer_combo.setEditText(layer or "")
        self.length_spin.setValue(float(length_m))

    # -- internals ----------------------------------------------------------
    def _select_label(self, label):
        for i in range(self.shape_list.count()):
            if self.shape_list.item(i).data(Qt.UserRole) == label:
                self.shape_list.setCurrentRow(i)
                return

    def _refill(self):
        family = self.family_combo.currentText()
        text = self.filter_edit.text().strip()
        shapes = self.db.search(text, family) if text else self.db.shapes(family)
        keep = self.current_shape().label if self.current_shape() else None
        self.shape_list.blockSignals(True)
        self.shape_list.clear()
        from PySide6.QtWidgets import QListWidgetItem
        for s in shapes:
            item = QListWidgetItem(s.label_for(self.unit_system()))
            item.setData(Qt.UserRole, s.label)
            self.shape_list.addItem(item)
        self.shape_list.blockSignals(False)
        if keep is not None:
            self._select_label(keep)
        if self.shape_list.currentRow() < 0 and self.shape_list.count() == 1:
            self.shape_list.setCurrentRow(0)
        self._on_shape_changed()

    def _on_shape_changed(self):
        shape = self.current_shape()
        enabled = shape is not None
        self.place_button.setEnabled(enabled)
        self.update_button.setEnabled(enabled)
        if shape is None:
            self.readout.setText("")
            self.preview.set_profile(None)
            self.segments_spin.setEnabled(False)
            return
        self.segments_spin.setEnabled(bool(shape.round))
        units = self.unit_system()
        dims = shape.dims_mm if units == "metric" else shape.dims
        parts = [f"{k} = {fmt_dim(dims[k], units)}" for k in READOUT_KEYS.get(shape.family, [])
                 if k in dims]
        if units == "metric":
            parts.append(f"W = {shape.W_kgm:g} kg/m")
            parts.append(f"A = {shape.A_mm2:g} mm²")
        else:
            parts.append(f"W = {shape.W:g} lb/ft")
            parts.append(f"A = {shape.A:g} in²")
        self.readout.setText("   ".join(parts))
        profile = build_profile(shape.family, shape.dims_m(),
                                fillets=self.fillets_check.isChecked(),
                                segments=self.segments_spin.value())
        self.preview.set_profile(profile)
        self._on_point(self.preview.selected())

    def _on_point(self, insertion_id):
        profile = self.preview._profile
        label = insertion_id
        if profile is not None:
            label = profile.point(insertion_id).label
        self.insertion_label.setText(f"Insertion: {label}")

    def _on_place(self):
        if self.current_shape() is None:
            return
        self.place_requested.emit(self.params())

    def _on_update(self):
        if self.current_shape() is None:
            return
        self.update_requested.emit(self.params())
```

```python
    @staticmethod
    def _table(headers):
        t = QTableWidget(0, len(headers))
        t.setHorizontalHeaderLabels(headers)
        t.setEditTriggers(QTableWidget.NoEditTriggers)
        t.setSelectionBehavior(QTableWidget.SelectRows)
        t.horizontalHeader().setSectionResizeMode(QHeaderView.Stretch)
        t.verticalHeader().setVisible(False)
        return t

    @staticmethod
    def _fill(table, rows):
        table.setRowCount(len(rows))
        for r, values in enumerate(rows):
            for c, value in enumerate(values):
                table.setItem(r, c, QTableWidgetItem(str(value)))

    def refresh(self):
        self._bom = self._fetch()
        bom = self._bom
        self._fill(self.rows_table, [
            (r.mark, r.label, r.family,
             "profile" if r.is_profile else self._fmt_len(r.length_m),
             self._fmt_weight(r.weight_kg), r.layer, r.ifc_class) for r in bom.rows])
        self._fill(self.summary_table, [
            (s.label, s.family, s.count, self._fmt_len(s.total_length_m),
             self._fmt_weight(s.total_weight_kg)) for s in bom.summary])
        self.totals_label.setText(
            f"{bom.count} members  •  {self._fmt_len(bom.total_length_m)}  •  "
            f"{self._fmt_weight(bom.total_weight_kg)}")

    def _on_row_activated(self, row, _column=0):
        if self._bom is None or row < 0 or row >= len(self._bom.rows):
            return
        self._select(self._bom.rows[row].uid)

    def export_csv(self, path=None):
        if self._bom is None:
            self.refresh()
        if path is None:
            path, _f = QFileDialog.getSaveFileName(self, "Export Bill of Materials", "steel_bom.csv",
                                                   "CSV files (*.csv)")
            if not path:
                return None
        with open(path, "w", encoding="utf-8", newline="") as fh:
            fh.write(to_csv(self._bom, self._fmt_len, self._fmt_weight))
        return path
```

```python
# SPDX-License-Identifier: GPL-3.0-or-later
"""Extension wiring: toolbar, menus, context menu, Browser kind, and the
session object that owns the dialogs and turns tool callbacks into commands."""
from __future__ import annotations

import logging
import os

                    member_parts, member_record, new_params, rebuild_command, run)
from ._tools import PlaceMemberTool, StretchMemberTool
from ._units import fmt_len, fmt_weight

log = logging.getLogger("ingetrazo.plugins.igz_steel")

def load_icon(name, window):
    """icons/<name>.svg (light strokes) for a dark palette, <name>_light.svg
    for a light one; either file serves as the fallback for the other."""
    dark = True
    try:
        bg = window.palette().color(QPalette.Window)
        dark = bg.lightness() < 128
    except Exception:
        pass
    order = [f"{name}.svg", f"{name}_light.svg"] if dark else [f"{name}_light.svg", f"{name}.svg"]
    for fn in order:
        path = os.path.join(_ICONS, fn)
        if os.path.exists(path):
            return QIcon(path)
    return QIcon()


class SteelSession:
    def __init__(self, app, db):
        self.app = app
        self.db = db
        self.dialog = None
        self.bom_dialog = None
        self._edit_target = None

    # -- helpers ------------------------------------------------------------
    @property
    def scene(self):
        return self.app.viewport.scene

    def layer_names(self):
        return [ly.name for ly in getattr(self.scene, "layers", []) or []]

    def _guard(self):
        if getattr(self.scene, "edit_group", None) is not None:
            QMessageBox.information(self.app.window, "Steel",
                                    "Close the group you are editing before placing or "
                                    "changing steel members.")
            return False
        return True

    def single_selected(self):
        found = []
        for item in getattr(self.scene, "selection", ()) or ():
            g = getattr(item, "owner", None) or item
            if is_steel_group(g) and g not in found:
                found.append(g)
        if len(found) != 1:
            QMessageBox.information(self.app.window, "Steel",
                                    "Select exactly one steel member created with this extension.")
            return None
        return found[0]

    # -- dialogs ------------------------------------------------------------
    def member_dialog(self):
        if self.dialog is None:
            from ._dialog import MemberDialog
            self.dialog = MemberDialog(self.db, self.app.window)
            self.dialog.place_requested.connect(self.on_place)
            self.dialog.update_requested.connect(self.on_update)
        self.dialog.set_layers(self.layer_names())
        return self.dialog

    def _show(self, dialog):
        dialog.show()
        dialog.raise_()
        dialog.activateWindow()

    def open_place(self):
        d = self.member_dialog()
        d.set_mode("place")
        self._show(d)

    def open_edit(self):
        g = self.single_selected()
        if g is None:
            return
        params = member_params(g)
        from core.layers import layer_of
        d = self.member_dialog()
        d.set_mode("edit")
        d.load(params, layer_of(g), float(params.get("length", 0.0)))
        self._edit_target = g
        self._show(d)

    def open_stretch(self):
        g = self.single_selected()
        if g is None:
            return
        params = member_params(g)
        shape = self.db.find(params.get("label", ""))
        if shape is None:
            QMessageBox.warning(self.app.window, "Steel",
                                f"Unknown shape {params.get('label')!r} in this member.")
            return
        from core.layers import layer_of
        layer = layer_of(g)

        def on_commit(fixed, direction, length):
            return self.rebuild(g, params, fixed, direction, length, layer)
        self.app.viewport.set_active_tool(StretchMemberTool(g, shape, params, on_commit))

    def open_bom(self):
        if self.bom_dialog is None:
            from ._dialog import BomDialog
            self.bom_dialog = BomDialog(self.app.window, self.collect_bom, self.select_uid,
                                        fmt_len, fmt_weight)
        self.bom_dialog.refresh()
        self._show(self.bom_dialog)

    # -- actions ------------------------------------------------------------
    def on_place(self, p):
        shape = self.db.find(p.get("label", ""))
        if shape is None:
            return
        params = new_params(shape.label, p.get("unit_system", "imperial"),
                            p.get("insertion", "centroid"), p.get("roll", 0.0),
                            p.get("fillets", True), p.get("segments", 24))
        layer = (p.get("layer") or "").strip() or None

        def on_member(start, direction, length):
            return self.insert(shape, params, start, direction, length, layer)

        def on_profile(start):
            return self.insert(shape, params, start, (1.0, 0.0, 0.0), 0.0, layer)
        self.app.viewport.set_active_tool(PlaceMemberTool(shape, params, on_member, on_profile))

    def on_update(self, p):
        g = self._edit_target
        if g is None or not is_steel_group(g) or g not in list(iter_groups(self.scene)):
            QMessageBox.information(self.app.window, "Steel",
                                    "The member is no longer in the document. Select it again.")
            return
        shape = self.db.find(p.get("label", ""))
        if shape is None:
            return
        old = member_params(g)
        params = new_params(shape.label, p.get("unit_system", "imperial"),
                            p.get("insertion", "centroid"), p.get("roll", 0.0),
                            p.get("fillets", True), p.get("segments", 24))
        length = float(p.get("length", old.get("length", 0.0)))
        if length < MIN_LENGTH:
            length = 0.0
        layer = (p.get("layer") or "").strip() or None
        start = tuple(old.get("start", (0.0, 0.0, 0.0)))
        direction = tuple(old.get("direction", (1.0, 0.0, 0.0)))
        if self.rebuild(g, params, start, direction, length, layer) and self.dialog is not None:
            self.dialog.close()

    def insert(self, shape, params, start, direction, length, layer):
        if not self._guard():
            return False
        try:
            parts = member_parts(shape, params, start, direction, length)
            group = make_group(parts)
        except Exception as exc:
            log.exception("igz_steel: building a member failed")
            QMessageBox.critical(self.app.window, "Steel", f"Could not build the member: {exc}")
            return False
        err = run(self.app.viewport, insert_command(group, layer))
        if err:
            QMessageBox.critical(self.app.window, "Steel", err)
            return False
        self._refresh_bom()
        return True

    def rebuild(self, group, params, start, direction, length, layer):
        if not self._guard():
            return False
        shape = self.db.find(params.get("label", ""))
        if shape is None:
            return False
        try:
            parts = member_parts(shape, params, start, direction, length)
        except Exception as exc:
            log.exception("igz_steel: rebuilding a member failed")
            QMessageBox.critical(self.app.window, "Steel", f"Could not rebuild the member: {exc}")
            return False
        err = run(self.app.viewport, rebuild_command(group, parts, layer))
        if err:
            QMessageBox.critical(self.app.window, "Steel", err)
            return False
        self._refresh_bom()
        return True

    # -- queries ------------------------------------------------------------
    def collect_bom(self):
        records = [member_record(g, self.db) for g in iter_groups(self.scene) if is_steel_group(g)]
        return collect([r for r in records if r is not None])

    def select_uid(self, uid):
        for g in iter_groups(self.scene):
            if getattr(g, "uid", None) == uid:
                self.scene.selection.clear()
                self.scene.selection.add(g)
                self.app.viewport.update()
                return

    def _refresh_bom(self):
        d = self.bom_dialog
        if d is not None and d.isVisible():
            d.refresh()

    def on_document_changed(self):
        self._refresh_bom()
        if self.dialog is not None and self.dialog.isVisible():
            self.dialog.set_layers(self.layer_names())

    # -- host hooks ---------------------------------------------------------
    def context_menu(self, menu, selection):
        steel = []
        for item in selection:
            g = getattr(item, "owner", None) or item
            if is_steel_group(g) and g not in steel:
                steel.append(g)
        if len(steel) != 1:
            return
        menu.addSeparator()
        edit = menu.addAction("Edit steel member…")
        edit.triggered.connect(lambda _c=False: QTimer.singleShot(0, self.open_edit))
        stretch = menu.addAction("Stretch steel member")
        stretch.triggered.connect(lambda _c=False: QTimer.singleShot(0, self.open_stretch))

    def outliner_kind(self, group):
        if not is_steel_group(group):
            return None
        p = member_params(group) or {}
        shape = self.db.find(p.get("label", ""))
        length = float(p.get("length", 0.0))
        weight = length * (shape.weight_per_m() if shape else 0.0)
        from core.layers import layer_of
        return {"type": "Steel profile" if length < MIN_LENGTH else "Steel member",
                "props": [("Shape", p.get("label", "")), ("Length", fmt_len(length)),
                          ("Weight", fmt_weight(weight)), ("Layer", layer_of(group))]}


def _install_toolbar(app, session):
    win = app.window
    if win is None or not hasattr(win, "addToolBar"):
        return
    if win.findChild(QToolBar, TOOLBAR_NAME) is not None:
        return
    tb = None
    maker = getattr(win, "_new_toolbar", None)
    if callable(maker):
        try:
            tb = maker("Steel", TOOLBAR_NAME)
        except Exception:
            tb = None
    if tb is None:
        tb = QToolBar("Steel", win)
        tb.setObjectName(TOOLBAR_NAME)
        tb.setMovable(True)
        tb.setFloatable(True)
        px = 24
        try:
            from views.icons import toolbar_icon_px
            px = toolbar_icon_px()
        except Exception:
            pass
        tb.setIconSize(QSize(px, px))
        tb.setToolButtonStyle(Qt.ToolButtonIconOnly)
        win.addToolBar(Qt.TopToolBarArea, tb)
    entries = [("tb_place", "Place steel member…", session.open_place),
               ("tb_stretch", "Stretch steel member", session.open_stretch),
               ("tb_edit", "Edit steel member…", session.open_edit),
               ("tb_bom", "Steel Bill of Materials…", session.open_bom)]
    refs = []
    for icon, text, fn in entries:
        act = QAction(load_icon(icon, win), text, win)
        act.setToolTip(text)
        act.setStatusTip(text)
        act.triggered.connect(lambda _c=False, f=fn: QTimer.singleShot(0, f))
        tb.addAction(act)
        refs.append(act)
    tb._igz_steel_refs = refs
    return tb
```

```python
# SPDX-License-Identifier: GPL-3.0-or-later
"""Zip igz_steel/ into dist/igz_steel.zip (the catalog's ZIP-package layout)."""
from __future__ import annotations

import sys
import zipfile
from pathlib import Path

ROOT = Path(__file__).resolve().parent.parent
PKG = ROOT / "igz_steel"
SKIP_DIRS = {"__pycache__"}
SKIP_SUFFIXES = {".pyc", ".xlsx"}


def build_zip(out=ROOT / "dist" / "igz_steel.zip") -> Path:
    out = Path(out)
    out.parent.mkdir(parents=True, exist_ok=True)
    with zipfile.ZipFile(out, "w", zipfile.ZIP_DEFLATED) as zf:
        for path in sorted(PKG.rglob("*")):
            if path.is_dir() or any(part in SKIP_DIRS for part in path.parts):
                continue
            if path.suffix in SKIP_SUFFIXES:
                continue
            zf.write(path, "igz_steel/" + path.relative_to(PKG).as_posix())
    return out


if __name__ == "__main__":
    target = build_zip(Path(sys.argv[1]) if len(sys.argv) > 1 else ROOT / "dist" / "igz_steel.zip")
    print(f"wrote {target} ({target.stat().st_size // 1024} KB)")
```

```markdown
# igz_steel — AISC steel members for IngeTrazo

`igz_steel` places structural steel members with the dimensions of the
**AISC Shapes Database v16.0** (all 13 families: W, M, S, HP, C, MC, L, WT,
MT, ST, 2L, HSS and PIPE — 2,299 shapes), stretches them along any axis, edits
them in place, tags them for BIM, assigns layers and produces a Bill of
Materials.

- **Version:** 1.0.0 — **License:** GPL-3.0-or-later (see LICENSE, THIRD-PARTY.md)
- **Tested with:** IngeTrazo 0.5.8 (Extension API 2). The API is still 0.x; a
  newer IngeTrazo may need an update of this extension.
- **Dependencies:** none beyond IngeTrazo itself.

## Installation

In IngeTrazo open **Extensions ▸ Open plugins folder**, drop the `igz_steel`
folder there (or unzip `igz_steel.zip` so that the folder is
`plugins/igz_steel/`) and restart IngeTrazo. A **Steel** toolbar and an
**Extensions ▸ Steel** submenu appear.

## Using it

1. **Place member…** — pick a family and a shape (type part of the label to
   filter, e.g. `12X26`; switch to metric labels if you prefer `W310X38.7`).
   Click an insertion point on the section preview (centroid, top of steel,
   any corner or edge midpoint). Set roll, fillets, round segments and the
   layer (type a new name to create one). Press **Place**.
2. In the model the profile follows the cursor. **Click** the start point.
   Move along any axis (IngeTrazo's axis inference and arrow-key locks work as
   for the Line tool). **Click** the end point, or **type a length** in the
   Measurements box (`12'`, `3.5m`, `3660mm`…). **Esc** after the first click
   leaves a flat profile you can stretch later.
3. **Stretch member** — select a member, click the end you want to move, then
   click the new end or type the new total length. A click past the fixed end
   grows the member the other way.
4. **Edit member…** — select a member and change its shape, insertion point,
   roll, fillets, layer or length. The start point and axis stay put.
5. **Bill of Materials…** — every member with mark, shape, length, weight,
   layer and IFC class, a summary by shape and totals; **Export CSV…** writes
   the table. Double-click a row to select that member. Lengths and weights
   follow the document's units (feet-inches and pounds, or metres and
   kilograms).

Members are tagged **IfcColumn** (vertical), **IfcBeam** (horizontal) or
**IfcMember** (sloped). The Browser shows them as "Steel member" with shape,
length and weight.

## Notes and limits

- Geometry: parallel flanges at the tabulated average thickness (flange slopes
  on S, C, MC, M and MT are ignored); fillets from `kdes`; HSS corners at 2t
  outside and t inside; round sections as polygons (8–96 segments).
- Members placed while a group is open for editing are refused; close the
  group first. A member that was exploded or made unique can no longer be
  stretched or edited by this extension.
- The AISC data is reproduced for modelling only. Verify anything structural
  with a licensed engineer (see THIRD-PARTY.md for AISC's disclaimer).
```
